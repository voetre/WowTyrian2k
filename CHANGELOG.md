# Changelog

## 0.3.2
- Now on CurseForge, and installable from WowUp. No gameplay changes.

## 0.3.1
- Shorter, plainer text in the README, the options page and the setup menu. No gameplay changes.

## 0.3.0
- Jukebox controls: a panel under the game window with the song title, a progress bar, shuffle, previous, play/stop, next and loop buttons, and the visualizer settings. A track list sits beside it and can be folded away. Compact mode shows only the title, progress and media buttons. The settings are saved between sessions; shuffle always starts off.
- The game window uses the WoW settings-window style. The title bar shows the current screen, the level, difficulty and score, the jukebox song, and the flight time left.
- Options are split into sub-pages and use the WoW dropdowns and sliders. Game speed is a dropdown.
- Minimap button (LibDBIcon).
- WoW's own music is held off while the game is open and put back afterwards.
- Fixed: the "Show or hide Tyrian" key binding was missing (`Bindings.xml` wasn't included).

## 0.2.0
- First public release.
